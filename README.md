Intro
=====================

TEXEL is a 9mm x 9mm neuromorphic chip designed using the XFAB 180nm
XP018 technology. It implements mixed-signal in-memory spiking neural
networks emulating brain dynamics and integrating a calcium-based local
online plasticity rule. TEXEL offers the possibility to interface
non-volatile ferroelectric memristive devices, with either 2-terminals
(e.g. FTJ) or 3-terminals (e.g. FeFET), fabricated in back-end of line
processes to standard CMOS circuits, creating a novel hybrid
CMOS-memristive architecture. Alongside the main neuromorphic neuron
array, the chip also contains test structures to test individual hybrid
circuits principles and arrays of memristive devices.
